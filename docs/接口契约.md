# 实验二接口契约

本文件是阶段重建分支的设计目标；阶段一只确定契约，后续阶段逐步实现。

## 接口清单

| 方法 | 路径 | 请求体字段 | 成功 | 失败情形 |
| --- | --- | --- | --- | --- |
| GET | /api/students | 无 | 200，全部学生 | 500 未预期错误 |
| GET | /api/students/{studentNo}/scores | 无 | 200，课程编号、名称、学分、分数 | 500 未预期错误 |
| GET | /api/courses | 无 | 200，全部课程 | 500 未预期错误 |
| POST | /api/scores | studentNo、courseId、score | 201，含新 id 的完整记录 | 400 参数；404 学生或课程不存在；409 重复；500 未预期错误 |
| PUT | /api/scores/{id} | score | 200，修改后的完整记录 | 400 参数；404 成绩不存在；500 未预期错误 |
| DELETE | /api/scores/{id} | 无 | 204，响应体为空 | 400 参数类型；404 成绩不存在；500 未预期错误 |

学号不存在时查询成绩返回 200 和空列表。同一学生和课程不可重复录入；业务校验在 Service，格式校验在 DTO，Controller 使用 @Valid。

## 统一响应

成功：`{"code":0,"message":"ok","data":...}`。

失败：`{"code":非零业务码,"message":"中文错误说明","data":null}`。

删除成功是唯一例外：HTTP 204，无响应体。

## 错误码表

| 业务码 | HTTP | 触发条件 | message | 位置 |
| --- | --- | --- | --- | --- |
| 40001 | 400 | 学号空白 | 学号不能为空 | POST |
| 40001 | 400 | 课程编号空白 | 课程编号不能为空 | POST |
| 40001 | 400 | 分数缺失 | 分数不能为空 | POST、PUT |
| 40001 | 400 | 分数小于0或大于100 | 分数必须在 0 到 100 之间 | POST、PUT |
| 40001 | 400 | 请求无法解析、参数类型错误 | 请求参数不合法 | POST、PUT、DELETE |
| 40401 | 404 | 学生不存在 | 学生不存在 | POST |
| 40401 | 404 | 课程不存在 | 课程不存在 | POST |
| 40401 | 404 | 成绩不存在 | 成绩不存在 | PUT、DELETE |
| 40401 | 404 | 访问未映射的资源 | 资源不存在 | 未映射的路径 |
| 40901 | 409 | 学生和课程组合重复 | 该学生这门课程已录入成绩 | POST |
| 50000 | 500 | 未预期异常 | 服务器内部错误 | 全部接口 |

同一具体触发条件跨接口使用相同业务码和文案。校验失败返回第一条字段错误，服务器错误不得暴露堆栈。

## 验证顺序

预置数据包含所有学生课程组合；要验证创建成功，先删除 id=1，再创建 studentNo=2023010001、courseId=C001 的成绩。重启恢复初始数据，不能直接使用指导书中已存在的组合证明创建成功。
